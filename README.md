# 台股戰情室 tw-stock-warroom

每天自動抓取行情與新聞、重新訓練模型，產生一個靜態網站：

- **戰情總覽（電腦版一頁看完）**：左邊看好／看淡／大師精選名單，中間個股完整分析，右邊大盤判斷與即時新聞
- **大盤與個股未來 15 個交易日的預期走向**（預期路徑＋68% 可能區間），每檔附建議等級、信心值與判斷依據
- **個股查詢**：K 線、支撐壓力、停損參考，五個分頁——判斷依據、技術與 K 線型態、基本面與大師評分、籌碼、新聞公告
- **三位大師評分**：葛拉漢（防禦型價值 7 項）、巴菲特（品質護城河 7 項）、彼得林區（合理價成長 6 項＋六種股票分類），逐項列出通過與否
- **K 線型態**：28 種型態與技術訊號（錘子線、吞噬、晨星、紅三兵、跳空缺口、帶量突破、均線／KD／MACD 交叉、漲跌停…），每種都附近三年的歷史勝率與是否參與預測
- **籌碼**：三大法人買賣超與連續買賣天數、融資融券變化、券資比
- **選股雷達**：18 個篩選條件（大師選股、高殖利率、營收高成長、投信連買、融資暴增、有效 K 線型態、即將除權息、處置／注意股…）
- **前一晚美股連動**：費半、S&P 500 等對隔日台股的歷史影響，盤前自動納入預測
- **大波動事件、重大新聞、公司公告與風險提示**：列出可能原因與每則新聞的評分依據
- **復盤驗證**：過去每天的預測對照實際走勢，並自動產生改進建議、自動調整各項權重

不需要任何 API 金鑰，全部跑在 GitHub Actions 與 GitHub Pages 上。

> 本專案僅供研究與參考，不構成投資建議。

## 啟用步驟（只需做一次）

1. 到 repo 的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。
2. 到 **Actions → 每日更新 → Run workflow** 手動執行一次。完成後網址會顯示在該次執行的頁面上
   （通常是 `https://<帳號>.github.io/tw-stock-warroom/`）。
3. 之後會自動執行，不用再管。

> 私有 repo 要有 GitHub Pro 以上方案才能使用 Pages；免費方案請把 repo 設為公開。

## 自動更新時間

| 版本 | 台北時間 | 內容 |
|---|---|---|
| 盤前版 | 週一～五 07:17 | 已含前一晚美股收盤，適合開盤前參考 |
| 盤後版 | 週一～五 17:43 | 已含當日收盤價與三大法人買賣超，美股尚未開盤 |

GitHub 的排程可能延遲 10–30 分鐘。要改時間請編輯 `.github/workflows/daily.yml` 的 `cron`（UTC 時間）。

## 預測怎麼算

**個股 15 日預期報酬 ＝ β × 大盤預期報酬 ＋ 相對強度 × 個股波動 ＋ 美股隔夜調整**

| 部分 | 做法 |
|---|---|
| 相對強度 | 18 個技術因子（動能、均線乖離、RSI、MACD、KD、布林、量能、流動性、距高點位置等），每天以最近 500 個交易日、全股票池重新訓練的嶺迴歸。因子與目標都先排除波動與 β 的影響，回答「同樣風險下誰比較強」。 |
| 疊加因子 | 新聞情緒、籌碼（法人買賣超＋融資增減反向）、基本面品質與成長（ROE、毛利率、負債比、營收與 EPS 成長）、K 線型態（只採用歷史統計明確的型態）。沒有完整的樣本外回測，所以以較小權重疊加在相對強度上，並依復盤結果自動調整權重（0.3–2.0 倍）。 |
| 估值因子 | 本益比、淨值比、殖利率、EPS 成長的三年歷史（每 20 個交易日一個快照）。回測加入模型後樣本外 IC 由 0.031 降到 0.029——近兩年低本益比的股票 15 日內反而較弱——所以**不放進預測模型**，只用於大師評分與選股；每天仍檢驗它們的 IC，轉為有效時可在 `config.py` 的 `VALUE_FACTORS` 開啟。 |
| 大盤 | 大盤動能、市場寬度、費半、S&P 500、VIX 的強懲罰迴歸，再加新聞情緒微調。 |
| 美股隔夜 | 以歷史資料迴歸「前一晚費半、S&P 500 漲跌 → 隔日台股」的關係，並估計每檔股票的敏感度。 |
| 信心值 | 滾動回測（walk-forward，樣本外）中，同等強度的訊號 15 日後實際贏過股票池中位數的比例。基準 50。 |
| 建議等級 | 相對強度前 5% 強力看多、前 20% 偏多、後 20% 偏空、後 5% 強力看空；若與絕對預期報酬方向相反則降一級。 |

股票池：上市成交金額前 300、上櫃前 150 檔普通股，加上 0050、0056、00878。

### K 線型態的實際表現（近三年、450 檔）

教科書型態在台股不一定成立。系統用 15 日報酬重疊修正後的 t 值檢驗每種型態，目前結果大致是：
**動能型訊號有效**（漲停 t≈4、向上跳空與帶量突破 t≈3、長紅 K t≈2），**多數反轉型態沒有統計意義**
（錘子線、吞噬、晨星、低檔十字、KD 低檔黃金交叉都不顯著，甚至方向相反）。網頁「模型說明」會每天更新這張表。

### 請這樣解讀

- 模型擅長的是**排序**（哪些股票相對強），不是預測大盤漲跌，也不是保證個股上漲。
- 信心值多半落在 50–55 之間，這是技術面訊號的真實水準。
- 回測用的股票池是「現在」成交金額最大的股票，有倖存者偏誤，實際績效通常低於回測。
- 新聞情緒是關鍵字比對，會誤判反諷或複雜語意。
- 財報與月營收只有最新一期，大師評分無法回測，分數代表「符合大師條件的比例」，不是買賣訊號。
- 未計入交易成本、漲跌停無法成交等因素。

## 復盤與自我修正

每次執行都會把當天的預測存到 `data/predictions/`。之後每天拿來和實際走勢比對，計算：

- 相對強弱命中率（基準 50%）、絕對方向命中率（附同期上漲比例當基準）
- 看好前 10 名相對股票池的超額報酬、勝出天數比例
- 信心值校準（高信心是否真的比較準）
- 各因子近期是否失靈、新聞與籌碼疊加是否有幫助

新聞與籌碼的權重在累積 8 天以上的實際預測後，會依它們與實際超額報酬的相關性自動調整
（範圍 0.3–2.0）。首次執行時，最近 40 天的「歷史預測」是用樣本外回測補齊的，網頁上會標示為「回測」。

## 本機執行

```bash
pip install -r requirements.txt
python -m warroom.pipeline          # 抓資料、訓練、輸出到 site/data/
python -m http.server 8000 -d site  # 開 http://localhost:8000
python -m pytest -q                 # 單元測試（另需 pip install pytest）
```

第一次執行要補抓 20 天的法人與融資資料、三年的估值歷史，約需 10–15 分鐘；之後有快取，約 2–3 分鐘。

## 調整參數

所有參數集中在 [`warroom/config.py`](warroom/config.py)：股票池大小、預測天期、訓練視窗、
懲罰強度、疊加權重、建議等級門檻、大波動門檻等，都有中文註解。

## 專案結構

```
warroom/
  config.py     參數
  sources.py    證交所、櫃買中心、Yahoo Finance 資料；融資融券、公告與風險提示
  features.py   技術指標
  fundamentals.py 估值歷史、財報、月營收、葛拉漢／巴菲特／林區評分
  patterns.py   K 線型態偵測與歷史統計
  chips.py      法人連買天數、融資融券、籌碼分數
  model.py      相對強度模型、大盤模型、滾動回測、信心校準
  usmkt.py      美股隔夜連動
  news.py       新聞蒐集、去重、對應個股、情緒與衝擊評分
  explain.py    判斷依據與建議文字
  review.py     復盤、改進建議、權重自動調整
  pipeline.py   主流程
site/           靜態網站（index.html / app.js / style.css），site/data/ 由 CI 產生
data/           進版控的狀態：每日預測、法人／融資／估值快取、財報與月營收、新聞存檔、權重
tests/          單元測試
```
